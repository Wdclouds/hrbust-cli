# HRBUST Toolkit (哈理工数字化校园全栈开源 CLI 与 SDK)

<p align="center">
  <b>全屏命令中枢 TUI · 官方认证双通道投射 · 居中 ASCII 艺术 Logo · 考务学业生活全栈闭环 · 代理安全免疫</b>
</p>

哈尔滨理工大学（HRBUST）数字化校园全栈终端工具箱与开发 SDK。  
集成全新进化的交互式终端命令中枢（TUI）、老教务在线系统（课表/成绩/考试/自习室/培养方案）、网上办事大厅（一卡通水控/洗浴出码/流水账单）、以及教务处最新公告新闻。

---

## 🌟 核心特性矩阵

### 1. 🏛️ 认证体系物理解耦与官方通道投射
- **系统物理隔离**：严格区分【老教务在线 (JWZX)】与【网上办事大厅 (CAS / E-Hall)】两大独立系统，凭据分别安全隔离加密落盘，杜绝密码混用。
- **办事大厅独立认证中心 (`#auth-view` / `hrbust auth`)**：
  - **官方选项一：移动端扫码登录**：7px 物理定位点高保真 Unicode 字符二维码，手机微信 / 今日校园 / 哈理工移动端一扫即连，后台异步自动轮询状态换票；
  - **官方选项二：统一认证密码登录**：金智 CAS 动态加盐 AES-128-CBC 加密提交，支持直接在终端输入全校统一身份认证密码。

### 2. 🚿 生活服务与一卡通水控
- **浴室与热水实时大盘 (`hrbust water`)**：实时拉取全校 5 大浴场/热水机位空闲率，上下键选择闪电出码（4 位有效出水预约码）。
- **一卡通消费账单流水 (`hrbust card`)**：直接反代调取一卡通底层流水账单，统计近期总支出与各场所扣费明细。

### 3. 🎓 学业分析与考务日程
- **全科成绩单与加权 GPA (`hrbust score`)**：一键拉取本科至今所有学期各科成绩、平时/期末拆解、自动计算加权平均分与官方 GPA；内置未评教拦截友好防御。
- **期末考场与座位号大盘 (`hrbust exam`)**：期末考前秒查自己坐哪！自动抽取考试科目、考试时间、考场教学楼与座位号，按紧急程度计算倒计时。
- **培养方案毕业学分审查 (`hrbust plan`)**：比对教学计划大纲，自动核算必修/限选/通识各模块已修学分、尚欠学分与毕业修读完成率。
- **大课表与今日课程预报 (`hrbust today` / `schedule`)**：按周次节次生成排课矩阵。

### 4. 📢 资讯动态与自习找房
- **自习与多媒体教室 (`hrbust room`)**：按教学楼快速检索当前没课的空闲教室，自动高亮打标投影/机房专用教室。
- **公告全文阅读器 (`hrbust read <id>`)**：免登录在线阅读校内通告与教学新闻正文，自动清洗正文排版，无损修复官方 GBK 附件中文乱码。

### 5. 🔌 多端生态无缝接入
- **AstrBot 微信机器人插件 (`hrbust/integrations/astrbot_plugin`)**：支持群聊与私聊自然语言交互（查成绩、查考试、查浴室、查账单、查课表、查教室）。
- **Hermes Agent 原生适配器 (`hrbust/integrations/hermes_tool`)**：为 AI Agent 赋予哈理工数字化校园调度底座。

## 🚀 快速上手

### 1. 安装与环境准备

```bash
git clone https://github.com/Wdclouds/hrbust-cli.git
cd hrbust-cli
pip install -e .
```

### 2. 启动命令中枢 TUI (强烈推荐)

直接在终端输入即可秒开全屏交互式命令中枢：

```bash
hrbust
# 或明确指定
hrbust tui
```

#### ⌨️ TUI 交互命令速查表

| 指令 | 快捷键 | 功能描述 |
| :--- | :--- | :--- |
| **`auth`** | - | 唤起**网上办事大厅官方认证中心**（官方扫码与统一认证密码双通道投射） |
| **`login <学号> <密码>`** | - | 登录**教务在线 (JWZX)**（查成绩/考试/课表/计划） |
| **`water`** | - | 展开全校 5 大浴场/热水实时大盘，表格行选中按 `Enter` 闪电预约出码 |
| **`card`** | - | 展开一卡通近期洗浴/热水消费流水账单与累计支出统计 |
| **`score`** | - | 展开本科全科学分、加权平均分与 GPA 绩点大盘 |
| **`exam`** | - | 展开期末/期中考试科目、考试时间地点、座位号与倒计时大盘 |
| **`plan`** | - | 展开专业培养方案教学计划大纲、已修/尚欠学分与毕业完成度审查 |
| **`room [楼栋] [-m]`** | - | 检索教学楼空闲自习室（如 `room 南一`，加 `-m` 仅筛选多媒体机房） |
| **`today` / `schedule`** | - | 查看今日日程与学期排课大表 |
| **`news` / `notice`** | - | 查看官方通告与新闻摘要（在表格行按 `Enter` 唤起正文阅读器） |
| **`read <文章ID>`** | - | 在线阅读通告正文并列出附件下载链接 |
| **`status`** | - | 检查教务在线、办事大厅与校园网三方状态 |
| **`home`** | **`Esc`** | 随时一秒平滑切回居中 ASCII Logo 首页 |
| **`exit`** | **`q`** | 优雅退出 TUI 界面 |

### 3. 命令行快捷指令 (CLI 批处理模式)

除全屏 TUI 外，所有功能均支持以脚本化 CLI 命令单次调用：

```bash
# 1. 独立认证体系
hrbust login -u 2306010309 -p ********   # 绑定教务在线账号密码
hrbust auth                             # 唤起办事大厅官方双通道认证菜单
hrbust auth --qr                        # 快捷指令：直接在终端打印字符二维码扫码

# 2. 生活与水控
hrbust water                            # 查看浴室空闲率并一键出码
hrbust card                             # 查看一卡通消费流水账单与支出总计

# 3. 学业与考务
hrbust score                            # 个人成绩大盘与加权平均 GPA
hrbust exam                             # 期末考场教室、座位号与考试倒计时
hrbust plan                             # 培养方案学分审查与毕业完成度
hrbust today                            # 今日课程预报

# 4. 自习与教室
hrbust room                             # 交互式选择教学楼
hrbust room 南一 --media                # 仅筛选南一多媒体自习室

# 5. 官方资讯
hrbust news                             # 教学新闻
hrbust notice                           # 教务公告
hrbust read 5534                        # 阅读文章正文详情与附件下载
hrbust daily                            # 过去 24 小时增量资讯汇总
hrbust status                           # 系统独立凭据状态巡检
```
