# HRBUST AstrBot 微信机器人插件

哈尔滨理工大学（HRBUST）数字化校园全栈服务 AstrBot 微信机器人插件。  
支持在微信个人号、企微机器人或班级/宿舍微信群中，通过纯中文自然语言直接交互。

---

## 🌟 核心功能一览

| 触发口令 | 功能描述 |
| :--- | :--- |
| **`查浴室` / `洗澡`** | 实时获取全校 5 大浴场与热水机位空闲率及拥挤度建议 |
| **`约洗澡 南区男浴`** | 闪电申请 4 位出水预约码（有效时长 60 分钟） |
| **`取消预约` / `退水控`** | 一键取消已占用的预约码，释放机位供他人使用 |
| **`查成绩` / `gpa`** | 查询本科全部已修课程、平时/期末拆解、学分与官方加权 GPA |
| **`查考试` / `座位号`** | 查询期末/期中考试科目、考试时间地点与考场座位号 |
| **`查消费` / `账单`** | 查询一卡通近期洗浴与热水扣费明细流水与支出累计 |
| **`查学分` / `培养方案`** | 查询培养方案各模块完成度、已修得学分与毕业尚欠学分 |
| **`查教室 南一`** | 检索当前空闲教室，自动高亮打标多媒体与实验机房 |
| **`查课表` / `今日课程`** | 查看今日排课日程与节次教室 |
| **`新公告` / `查更新`** | **增量推送**：只推送上次已读时间戳之后的未读通知，不重复刷屏 |
| **`全部已读`** | 一键重置未读水位线，消除红点 |
| **`今日教务`** | 全量速览教务处今日发布的公告与新闻动态 |

## 🚀 部署指引

### 1. 自动挂载至 AstrBot 容器
将本目录整体复制（或软链接）至 AstrBot 容器的插件目录：

```bash
# 宿主机或容器内
cp -r hrbust/integrations/astrbot_plugin /opt/astrbot/data/plugins/astrbot_plugin_hrbust
```

### 2. 依赖声明
确保运行环境中已安装 Python 基础依赖库：
```bash
pip install requests beautifulsoup4 pycryptodome pillow
```

### 3. 重启机器人服务
在 AstrBot 管理面板或终端中重启机器人，插件即可自动加载激活！
